# RecipeHub

RecipeHub — full-stack вебзастосунок для роботи з рецептами та інгредієнтами (автентифікація, CRUD, валідація даних).

## Tech stack

- Next.js 16 (App Router)
- TypeScript
- NextAuth (Auth.js) + Prisma Adapter
- Prisma + PostgreSQL
- Tailwind CSS v4 + HeroUI
- Zustand
- Zod
- Vitest

## Requirements

- Node.js 18+
- PostgreSQL 14+

## Setup (local)

npm install
npm run dev

Open [https://next-project-woad-one.vercel.app/](https://next-project-woad-one.vercel.app/) with your browser to see the result.

## Minimal keys:

DATABASE_URL=
NEXTAUTH_URL=
NEXTAUTH_SECRET=
